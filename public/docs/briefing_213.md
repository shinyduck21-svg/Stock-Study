> **핵심 내용 요약**

**1\. “AI는 이제 챗봇 단계를 넘어 실제 노동 단계로 간다”**

젠슨 황은 AI를 단순 질의응답 시스템이 아니라 “디지털 노동자(digital agents)” 단계로 규정했습니다.

그는:

• AI assistant → coworker → autonomous agent

• 추론(reasoning)

• 계획(planning)

• 도구 사용(tool use)

• 반복 검증(iteration)

구조로 발전한다고 설명했습니다.

즉 이제 AI는 “답변 생성”이 아니라 실제 업무를 끝낼 때까지 반복적으로 작동하는 방향으로 이동한다는 것입니다.

* * *

**2\. 그래서 컴퓨팅 수요가 기존과 차원이 달라진다**

젠슨 황은 Agentic AI 시대에는 inference(추론) 연산량이 폭증한다고 설명했습니다.

과거 LLM은:

• 질문 1회 → 답변 1회

였다면,

에이전트 AI는:

• 생각

• 검색

• 코드 실행

• 검증

• 재시도

• 멀티스텝 추론

을 반복 수행하기 때문에 GPU 사용 시간이 훨씬 길어진다는 논리입니다.

그는 Dell 행사에서 토큰 수요가:

• 현재 약 10조 토큰

• 2028년에는 1경(quadrillion) 토큰

수준까지 갈 수 있다고 언급했습니다.

이 흐름은 결국:

• GPU

• HBM(High Bandwidth Memory)

• NAND/스토리지

• 네트워킹

• 전력·냉각

전체 AI 인프라 수요 증가로 연결된다는 논리입니다.

* * *

**3\. “AI Factory”라는 개념 등장**

젠슨 황과 마이클 델은 앞으로 기업들이 단순 서버룸이 아니라:

“AI Factory”

를 구축하게 될 것이라고 설명했습니다.

이 개념은:

• 데이터 입력

• 모델 학습

• 추론

• AI agent 운영

• 디지털 생산성 생성

을 공장처럼 지속적으로 수행하는 구조입니다.

젠슨 황 표현으로는:

“We are manufacturing intelligence.”

즉 “이제 기업은 지능(intelligence)을 생산하는 공장”이라는 것입니다.

* * *

**4\. AI는 클라우드만으로 끝나지 않는다**

젠슨 황은:

• 기업 핵심 데이터

• 제조 데이터

• 의료 데이터

• 금융 데이터

• 보안 데이터

는 외부 클라우드로 모두 보내기 어렵다고 설명했습니다.

그래서 AI는:

• 공장

• 병원

• 자동차

• 기업 내부 서버

• PC

같은 현장(on-premise / edge)에서 직접 작동해야 한다고 주장했습니다.

이는 결국:

• 엔터프라이즈 AI 서버

• Edge AI

• AI PC

• 온프레미스 GPU

수요 폭증 논리로 이어집니다.

이 때문에 AI가 단순히 질문에 답할 때보다 훨씬 오래 작동하게 되고, 필요한 연산량도 기존보다 100배에서 1,000배까지 늘어날 수 있다고 강조함

* * *

**5\. 삼성 SDS 사례 언급**

Dell 행사에서는 Samsung SDSCEO도 등장했습니다.

여기서:

• 기업 내부 AI

• 제조 자동화

• Hyper Automation

• GPU 부족 현상

• 보안형 AI 인프라

사례가 소개됐습니다.

즉 AI가 실제 제조·업무 현장으로 들어가기 시작했다는 사례로 사용된 것입니다.

* * *

**6\. 가장 큰 병목은 결국 메모리와 첨단 반도체**

젠슨 황은 반복적으로:

• 첨단 공정

• HBM

• 첨단 패키징(CoWoS)

• 메모리

가 AI 시대 핵심 병목이라고 설명해왔습니다.

그래서 NVIDIA는:

• SK hynix

• Micron Technology

• TSMC

등과 수년 전부터 로드맵을 맞춰왔다고 언급했습니다.

* * *

**7\. 이 흐름을 “단순 AI 버블”로 보기 어려운 이유**

인터뷰 전체 핵심은 사실 이것입니다.

젠슨 황은 지금 상황을:

• 단순한 GPU 교체 사이클

• 일시적 IT 투자 붐

이 아니라,

“컴퓨팅 패러다임 자체의 변화”

로 설명합니다.

즉:

• 소프트웨어 시대 → AI Factory 시대

• CPU 중심 → Accelerated Computing

• Human labor → Digital labor

로 경제 구조가 바뀌고 있다는 시각입니다.

그래서 그는 AI 인프라 구축이:

• 매우 초기 단계이며

• 10년 이상 지속될 가능성을 반복적으로 시사하고 있습니다.
